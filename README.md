<h2>About Me</h2>
<p>I’m a long-time Joomla enthusiast and contributor, active since the Mambo days. I was part of the Joomla Bug Squad from 2010 to 2024 and contributed to several releases and fixes. I’m also a photographer, woodworker, and gamer — living a simple life in McCord, Oklahoma.</p>

<h2>Featured Projects</h2>
<ul>
<li><a href="https://github.com/N6REJ/joomla-packager">Joomla Packager</a> – Automates packaging and releasing Joomla extensions with GitHub Actions.</li>
<li><a href="https://extensions.joomla.org/extension/bears-pricing-tables/">Bears Pricing Tables</a> – A flexible, responsive pricing table module with 12 templates, FontAwesome support, and full Joomla 5 compatibility.</li>
<li><a href="https://extensions.joomla.org/extension/bears-clock/">Bears Clock</a> – A live JavaScript/PHP clock that supports timezone-aware display using PHP’s advanced date functions.</li>
<li><a href="https://extensions.joomla.org/extension/bears-julian-clock/">Bears Julian Clock</a> – A Julian-format live clock with up to 10-digit decimal display, based on JavaScript and PHP.</li>
<li><a href="https://magazine.joomla.org/all-issues/september-2022/bearsampp-portable-development-stack?highlight=WzJd">Bearsampp</a> – A portable WAMP stack tailored for Joomla developers, supporting multiple PHP versions and databases.</li>
